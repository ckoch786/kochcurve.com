# Read me

## Setup Instructions

1. **Install Jekyll**:
   ```bash
   gem install jekyll bundler
   ```

2. **Create the site structure** with all files above

3. **Install dependencies**:
   ```bash
   bundle install
   ```

4. **Run locally**:
   ```bash
   bundle exec jekyll serve
   ```

5. **Visit**: `http://localhost:4000`

## Deploy to GitHub Pages

1. Create a repository named `username.github.io`
2. Push your code
3. GitHub will automatically build and deploy your site
4. Visit `https://username.github.io`

## Customization Tips

- Update `_config.yml` with your information
- Add more posts in `_posts/` with format `YYYY-MM-DD-title.md`
- Customize colors in `_sass/main.scss`
- Add more pages as needed
- Configure SEO tags and social metadata

Your blog is ready to go!
